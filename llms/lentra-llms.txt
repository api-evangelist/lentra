# Lentra

> Lentra is a Pune, India based cloud-native digital lending platform for banks and NBFCs. It
> covers loan origination, loan management, credit decisioning, bureau access, KYC/verification
> and collateral management, packaged as pre-built retail, business and agriculture lending
> journeys. Lentra sells to financial institutions directly and does NOT operate a public
> self-service developer portal, publish an open API reference, or ship API client SDKs.

## Status for agents

- No public OpenAPI, AsyncAPI, GraphQL or webhook specification is published.
- No public API base URL, authentication documentation, sandbox, or API keys.
- No public changelog, status page, deprecation policy, CLI, or MCP server.
- API access is obtained through a commercial engagement — start at the website contact/demo flow.
